# CCIH Integra

Design system do sistema integrativo de controle da CCIH (Comissão de Controle de Infecção Hospitalar).

- `ccih-integra/README.md` — guia da marca: princípios, voz, cores, tipografia, gráficos, iconografia.
- `ccih-integra/01-…06-*.md` — tipos de IRAS e como identificar, indicadores e fórmulas, registros de prontuário e cirurgia, rastreabilidade e testes da CME, treinamentos/processos/insumos, modelo de dados integrado.
- `ccih-integra/tokens.json` — tokens de cor (claro/escuro), tipografia, espaçamento, raios.
- `ccih-integra/components/` — `bundle.js` (`window.Integra`, React 18), `bundle.css`, `index.d.ts`, e guia + prévia de cada componente, incluindo o painel de referência `PainelCCIH`.
