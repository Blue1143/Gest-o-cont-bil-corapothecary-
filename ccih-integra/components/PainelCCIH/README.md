# PainelCCIH

Página de referência que compõe o painel integrado da CCIH com todos os componentes.

Ordem recomendada: cabeçalho com filtros → alerta crítico (se houver) → KPIs → tendência e distribuição de IRAS → processos (consumo de preparação alcoólica, treinamentos) → notificações recentes → CME (ciclo, auditoria) → insumos. Não é um componente exportado; copie a composição.
