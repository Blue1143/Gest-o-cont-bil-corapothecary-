# TrainingProgress

Cobertura de treinamentos por tema, com meta, contagem e status.

**Props**: `title`; `meta` (%, padrão 90); `band` — tolerância em pontos percentuais para Atenção (padrão 15); `itens` — `[{ tema, publico, concluidos, total, proximaReciclagem? }]`.

- Ordene por prioridade do programa, não por percentual.
- A cor da barra segue o status; o número e o selo trazem o significado.
